# Visualizing Federal Sponsor-Cosponsor Networks with Networkx and Plotly
Congress.gov allows users to download metadata about groupings of bills. The metadata available includes bill number, bill title, sponsor, cosponsors, date of introduction, and summary. Some of the available groupings include Congress number, Legislative Subject Term, and Policy Area. 

This notebook takes metadata for income tax rate bills of the 118th Congress and visualizes a network of sponsors and cosponsors as connected by sponsored bills. Sample bill data and output are stored in the Data and Output folders of this repository.
